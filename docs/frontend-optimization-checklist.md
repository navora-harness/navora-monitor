# 前端体验优化清单

日期：2026-10-12。基线：0.3.38 / 1107a3f。状态：实施中，具体实现和验证见 [优化实施记录](./optimization-progress.md)。

与 [录像与回放改造方案](./remediation-plan.md) 配套：后者解决媒体安全、定位与调度，本清单覆盖功能、界面逻辑、样式、动效、移动端和前端工程。

依据为当前 Vue/CSS 代码和用户反馈，本轮没有运行界面进行视觉验收。文中“现状”是代码可确认的行为；“建议”是设计目标，不能视为已经验证的视觉缺陷。已有搜索、批量操作、分组、框选导出、快捷键、暗色主题和移动抽屉，应优化而非重复开发。

优先级：P1 阻碍核心操作或导致误解/误操作；P2 一致性、效率和可访问性；P3 完善功能。勾选仅在功能实现并通过验收后进行。

## A. 回放与时间轴：首先优化的核心路径

- [ ] **F01 / P1 · 加载状态可信。** 现状：PlaybackView 有 loadPhase、buffering、ready 与 spinner 补救逻辑。改为统一展示未选通道、无录像、准备播放、定位中、缓冲、播放、暂停、正在录制暂不可播、失败。准备与缓冲用用户能懂的文案，不显示引擎名和内部阶段。验收：未出帧不显示已播放成功；失败有原因和可用操作；取消后旧结果不能改写当前状态。位置：PlaybackView、播放控制器。依赖：媒体任务状态与前端操作取消。
- [ ] **F02 / P1 · 加载时允许更换目标。** 现状：App 将 playbackBusy 传入 scrubLocked，TimelinePanel 多处阻止操作。目标：允许平移、缩放和选择新时间，新定位取消旧定位；导出选区与播放定位不要互相锁死。验收：连续拖动最后目标优先，不能卡在“请稍候”；后端未提供安全取消前不单独解除锁定。位置：App、TimelinePanel、PlaybackController。
- [ ] **F03 / P1 · 区分目标时间、实际播放时间和浏览视口。** 拖动时可显示目标时间，出帧后显示实际落点；浏览历史不被自动跟随拉回。提供明确“跟随播放”和“回到最新”入口。验收：播放头、画面时间与所选日期一致；用户平移后跟随暂停，恢复由明确操作触发。位置：TimelinePanel、wall-time、App。
- [ ] **F04 / P1 · 空档与录像状态可辨认。** 正常录像、正在写入、待准备、保存片段、缺口、不可用不能仅靠颜色区分；增加图例、文字/纹理和原因提示。点空档按统一规则跳至下一可播时间并说明，不能停在不可播放位置假装成功。验收：真实缺口不被画实，未知时长不显示假精度。依赖：真实索引与生命周期。
- [ ] **F05 / P2 · 时间轴工具分层。** 现状：日期、倍速、连续、框选、适应、定位、刷新集中在工具条；移动端连续缩写为“连”。常用保留日期、时间定位、缩放与跟随；刷新等放更多菜单，导出进入独立选区模式。移动端用完整名称。验收：窄屏不挤压主播放操作，各入口可在触屏发现。
- [ ] **F06 / P2 · 统一播放控制。** 现状：倍速在播放器和时间轴都有入口。选择播放器作为主要入口；若保留时间轴快捷入口，必须共享状态与可选值。时间轴管理查找，播放器管理播放。验收：任一入口切换立即一致，重新载入不意外回到 1×；不展示实际不支持的倍速行为。
- [ ] **F07 / P2 · 精确找录像。** 在已有日期筛选外增加输入日期+时分秒定位、上一/下一可播段、匹配不到时跳转提示。查询保持通道上下文。验收：输入非法值就地提示；跨日期、午夜与缺口行为可预测，不用反复滚动找目标。
- [ ] **F08 / P1 · 保存与导出是完整流程。** 区分“保存最近 N 分钟”和“选区导出”；显示起止、有效录像时长、缺口、输出位置和空间风险。提交后有任务进度/阶段、取消、失败重试与完成后打开文件。验收：请求提交不等于导出完成；不会重复提交；后端无进度时显示真实阶段而非虚构百分比。依赖：导出任务 API。
- [ ] **F09 / P2 · 离开回放保留上下文。** 记住当前通道、日期、视口、倍率和暂停/播放意图；退出回放返回原宫格布局，重新进入可继续或明确回到最新。验收：跨通道状态不串用，刷新后不自动启动大量旧播放器；失效文件有降级提示。

## B. 实时预览与设备管理

- [ ] **F10 / P1 · 分清选中设备和选中画面。** 设备树、宫格与底部操作显示同一明确通道；空槽位不可执行截图/保存/停止录制等通道操作。验收：每个危险操作明确目标名称，切换选择时旧异步结果不覆盖新设备。位置：App、MosaicView、DeviceTree。
- [ ] **F11 / P1 · 通道状态与操作反馈统一。** 在线、预览中、录像中、重连、停止、禁用、鉴权失败、编码不支持分开表达。停止预览与停止录像名称和图标不可混用。验收：用户能判断录制是否继续；失败有重试或配置入口，不只显示黑屏。
- [ ] **F12 / P2 · 宫格布局与操作可发现。** 保留现有拖放、交换、移出宫格，并提供点击选择设备、更多菜单和键盘替代。拖动前显示源，目标高亮，取消可恢复；双击放大与全屏有明显退出入口。验收：不使用拖拽也能完成分配/交换/移除；移动端不用模拟桌面拖拽。
- [ ] **F13 / P2 · 搜索与批量结果可理解。** 优化已有设备/分组搜索，展示命中数量、无结果和清除筛选；批量操作展示成功/失败数量与失败设备。搜索过滤不能悄悄扩大批量作用范围。验收：执行前明确已选 N 台，部分成功可以只重试失败项。
- [ ] **F14 / P2 · 扫描、添加、编辑形成闭环。** 已有扫描与属性窗口补齐扫描阶段、取消、去重、连接测试结果、密码显隐和字段级错误。保存成功后定位新设备，未保存修改关闭时提示。验收：慢请求不重复添加，鉴权错误与连接超时区分，不把凭据暴露到普通日志。
- [ ] **F15 / P3 · 常用工作区。** 在已有布局持久化基础上评估命名布局、恢复默认、最近使用通道和常用分组。验收：可删除或重命名布局；不存在设备可替换，不因恢复布局自动开启无限多路预览。先验证需求再增加入口。

## C. 信息架构、反馈和界面逻辑

- [ ] **F16 / P1 · 重要通知不被覆盖。** 现状：App 使用单条 status 消息承载大量动作。分为短暂成功提示、可操作错误、持续警报和任务列表；磁盘满/录制停止不能被普通刷新消息顶掉。验收：成功提示不抢焦点；严重错误持续可见；历史可查且不会无限累积。
- [ ] **F17 / P1 · 危险操作说明对象与后果。** 删除保存片段、清空录像、删除设备、停止批量录制分别采用与风险匹配的确认，明确是否删除录像；可逆的移出宫格用撤销，不可逆删除不能承诺假撤销。验收：默认焦点与 Enter 不误触危险动作，执行中防重复提交。
- [ ] **F18 / P2 · 设置按任务组织。** 在现有分区基础上梳理录像与存储、播放与预览、远程访问、服务、外观、诊断。区分即时生效与需重启；未保存修改有反馈；路径、空间和实际监听状态展示可信。验收：修改失败不显示已保存，关闭远程不只改变 UI。依赖：远程监听策略。
- [ ] **F19 / P2 · 统一弹窗、菜单和抽屉行为。** 复用现有 Escape 栈，补齐焦点进入/返回、顶层关闭、背景不可交互、标签和嵌套规则；文件选择窗口与普通表单保持一致。验收：一次 Esc 只关一层，Tab 不逃出模态，编辑未保存不被遮罩误关。位置：ServerDialogs、各 Dialog、escape-stack。
- [ ] **F20 / P2 · 文案与术语统一。** 明确预览/录像/回放、保存片段/导出、移出画面/删除设备的区别；“适应”“定位”补足具体对象。技术错误提供可展开诊断，日常界面保留用户可执行的建议。验收：关键入口只读文字也能理解；无含混缩写和内部变量名。
- [ ] **F21 / P2 · 桌面与远程体验共用行为。** 主 App 与 RemoteApp 共用播放状态、选择规则、通知和快捷键适配；受限功能隐藏或说明原因，权限由服务端执行。验收：相同操作不在两个入口出现不同含义；不能以按钮隐藏替代权限检查。

## D. 样式与视觉规范

- [ ] **F22 / P2 · 补齐设计变量和组件样式。** 现状：styles.css 已有明暗主题变量，PlaybackView 等仍大量使用固定颜色和局部尺寸。统一空间、字号、控件高度、圆角、层级、语义颜色及图标；视频画布可以保持深色，但周边控件须符合主题规则。验收：明暗切换无不可读标签，新增组件不再复制整套按钮 CSS。
- [ ] **F23 / P2 · 信息层级与密度。** 画面和当前时间优先；通道名称/录制状态其次；文件名与技术详情进入辅助信息。给设备名、路径和长错误提供可复制的完整详情。验收：常见窗口宽度下不挤掉核心控制；截断有可访问的展开入口。尺寸和布局需实际截图验证后定稿。
- [ ] **F24 / P2 · 控件全状态一致。** 覆盖默认、悬停、按下、选中、焦点、禁用、忙碌、失败；不能用透明度一个样式混合表达所有状态。验收：禁用有可发现的原因；键盘 focus-visible 清晰；按钮宽度不因文案或 spinner 变化跳动。
- [ ] **F25 / P2 · 颜色之外的可读性。** 录像、保存、选区、当前播放不能只靠绿/蓝/红；数字时间使用等宽数字；长时间监看减少非必要高亮。验收：灰度和色觉模拟仍能区分关键状态，明暗主题检查文字和控件边界对比度。
- [ ] **F26 / P2 · 响应式与缩放。** 覆盖 360/390/768/1280/1920 宽度、横竖屏、系统字体放大、浏览器 200% 缩放、触屏安全区与软键盘。现有界面 viewport 配置包含 maximum-scale=1，核查并移除阻碍用户缩放的限制。验收：核心任务无需页面横向滚动，表单底部不被软键盘遮挡，浮层不越屏。

## E. 动效与操作手感

- [ ] **F27 / P2 · 建立统一动效规则。** 当前有按钮 120ms、抽屉 220ms、控件显隐等局部动画。统一微反馈 100–150ms、菜单/浮层 150–200ms、抽屉 200–250ms 的候选范围；优先 transform/opacity，时长经实际设备验证。验收：动画可中断，连续点击不会排队；动画不阻挡操作或改变成功时机。
- [ ] **F28 / P1 · 交互立即反馈，真实状态随后确认。** 拖动立即更新目标标记，真实画面与时间在解码后提交；加载期间可保留上一帧但明确标记定位中，失败不能让旧画面冒充目标。验收：输入到可见反馈候选 p95 ≤100ms，实际定位性能另测；避免高分辨率同步截图编码阻塞拖动。
- [ ] **F29 / P2 · 弹窗与抽屉完整进出场。** 当前多处 v-if 与入场 keyframes；核查退出是否突兀。统一进出与手势回弹；拖动中停用自动过渡，释放后完成或回弹。验收：退出动画期间不再可点击旧内容；焦点恢复与滚动锁释放时机正确。
- [ ] **F30 / P2 · 控件显隐不影响操作。** 视频悬停工具栏、倍速、音量与宫格按钮支持触屏常驻/点按展开、键盘聚焦可见；菜单打开时不自动隐藏。验收：鼠标移到按钮上不会消失，触屏第一次点按不意外执行隐藏动作。
- [ ] **F31 / P2 · 减少动态效果支持。** 本轮搜索未发现 prefers-reduced-motion 规则。增加全局减弱动效策略：关闭滑入、缩放和连续闪烁，保留必要状态文字；降低无意义 spinner 的视觉负担。验收：启用系统减少动态效果后所有主要页面生效，录像中状态不靠闪烁识别。
- [ ] **F32 / P2 · 时间轴与列表运动稳定。** 缩放围绕鼠标/手势锚点；用户拖动时不自动 fit、不改日期、不抢滚动；新增片段保持视口。大量条目用可见范围计算，批量 DOM 更新在帧边界执行。验收：复杂时间轴手势无明显跳动，性能分析确认而非靠增加过渡掩盖掉帧。

## F. 移动端、键盘与质量保障

- [ ] **F33 / P1 · 移动端任务布局。** 回放将画面、主控制和时间轴按优先级布局，次要项收纳；触控目标以至少 44×44 CSS px 为设计目标。增加横屏适配和选区开始/结束时间输入，避免强依赖精细拖拽。验收：手机可独立完成选择设备→找录像→播放→返回，不依赖 hover/title 或右键。
- [ ] **F34 / P2 · 可访问的键盘操作。** 在已有空格、方向键、F/M 和 Esc 行为上补齐焦点作用域、输入框与弹窗避让；设备树、菜单、范围/音量控件有可访问名称。媒体快捷键只作用于当前播放器。验收：全程键盘完成核心任务，输入时间时不意外跳片或静音；重要任务结果适度 aria-live 提示，不逐帧播报时间。
- [ ] **F35 / P2 · 前端状态与组件职责。** App/RemoteApp 管理壳层和路由意图；共享 composable 管理通道选择、播放会话、通知与任务；播放器适配层负责媒体状态；TimelinePanel 负责视口和选区。降低 playNonce/scrubNonce、多个 watch 和兜底定时器之间的隐式耦合。验收：切通道/卸载/重连正确释放播放器、监听与定时器；不做一次性大重写。
- [ ] **F36 / P1 · 增加交互回归与视觉验收。** 纯函数测试继续保留，新增浏览器核心流程：随机拖动取消、切设备竞态、倍速一致、框选导出、弹窗焦点、批量部分失败、移动抽屉。视觉截图覆盖明暗、空/加载/错误/正常状态与典型宽度。验收：每个发布阶段有可复用回归；媒体真实出帧检查与 mock UI 测试分开报告。

## 推荐交付批次

### U1：核心反馈与防误操作

F01–04、F08、F10–11、F16–17、F28、F33 的核心路径、F36 的基础回归。优先让用户知道操作对象、等待原因和下一步。播放取消、真实时间和任务进度随后端对应阶段交付，不通过假进度或隐藏错误提前宣称完成。

### U2：界面逻辑与操作效率

F05–07、F09、F12–14、F18–21、F34。先明确桌面/手机的导航和工具分层，再逐页调整，保留已有操作习惯。

### U3：视觉规范与动效

F22–27、F29–32、F33 的完整适配。先落地样式变量和基础控件状态，再改页面；减少动态效果与焦点样式可提前交付。完成截图与实际手势检查后验收。

### U4：工程收敛与可选功能

F35 随各批次逐步推进，F36 持续补齐；F15 命名布局按实际需求决定。避免先重构全部状态管理，再让用户等待体验改善。

## 放行规则

- 桌面与手机分别完成三条真实任务：实时查看/切换设备、按时间找录像并连续播放、保存/导出并找到结果。先测现状，再对比操作步骤、误操作、任务完成率和等待解释是否清楚，不伪造使用数据。
- 明暗主题、键盘、减少动态效果、窄屏与缩放通过；主要浮层不遮住用户必须操作的控件。
- 录制停止、磁盘满、连接失败等重要状态持续可见；成功提示不能掩盖它们。
- UI 动画、任务准备与媒体首帧使用不同指标；视觉流畅不能替代回放性能和数据正确性验收。
- 每批次保留当前布局设置的迁移兼容和恢复默认；不会因样式升级清空设备或改变录像计划。

本清单共 36 项。第一轮已落地部分核心交互和视觉基础，并完成隔离浏览器回归；整项勾选仍以本文完整验收条件为准，剩余范围见实施记录。
